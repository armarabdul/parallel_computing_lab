# Parallel Computing — OpenMP Practicals

This repository contains the **Parallel Computing practical programs** implemented using **OpenMP in C**.

##  Contents

### Experiment 1 — Parallel Merge Sort
**Question:**  
Write an OpenMP program to sort an array of `n` elements using both sequential and parallel merge sort using sections. Record the difference in execution time.

### Experiment 2 — Static Scheduling
**Question:**  
Write an OpenMP program to divide the iterations of a loop into chunks of 2 using `OMP_SCHEDULE=static,2`. Accept the number of iterations as input and display which iterations are executed by which thread.

### Experiment 3 — Fibonacci using Tasks
**Question:**  
Write an OpenMP program to calculate `n` Fibonacci numbers using OpenMP tasks.

### Experiment 4 — Prime Numbers
**Question:**  
Write an OpenMP program to find prime numbers from `1` to `n` using `parallel for`. Record the serial and parallel execution times.
